# Euclid, Elements I.47

This folder is a complete demo artifact for the static reader.

## Scope

- one canonical demo page image
- one reference PDF placeholder
- five aligned source regions
- modern English and math layers
- one self-contained Lean package
- static hover and tactic-state metadata

## Non-claims

- the shipped page image is a simplified derivative prepared for reader testing, not a diplomatic scan
- the Lean layer is a demo formalization scaffold aligned to the proposition theme, not a claim of full scholarly formalization of every historical proof detail
- hover metadata is static and precomputed
